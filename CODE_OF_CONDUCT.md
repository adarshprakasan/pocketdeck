# Code of Conduct

## Our standard

We want PocketDeck's project spaces to be welcoming and constructive. Treat people with respect, be patient with different backgrounds and experience levels, and focus feedback on ideas and work rather than people.

Harassment, discrimination, personal attacks, threats, and sharing someone's private information without permission are not acceptable.

## Responsibilities

Project maintainers may remove, edit, or reject contributions that do not follow this Code of Conduct and may temporarily or permanently restrict participation for behavior they consider inappropriate, threatening, or harmful.

## Reporting

Report conduct concerns privately to the project maintainer through the GitHub profile. For security vulnerabilities, use the private process in [SECURITY.md](SECURITY.md).
