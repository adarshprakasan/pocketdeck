# Security policy

## Supported version

Security fixes are intended for the latest published PocketDeck release. Please update to the latest release before reporting an issue when possible.

## Report a vulnerability

Please do not post exploitable security details in a public issue. Use GitHub's **Report a vulnerability** option on the [PocketDeck Security page](https://github.com/adarshprakasan/pocketdeck/security) to send a private report. Include the affected version, steps to reproduce, and potential impact. The maintainer will follow up through GitHub.

If private vulnerability reporting is unavailable, contact the maintainer through the GitHub profile before sharing details publicly.

## Scope

PocketDeck runs a local web server and pairs browsers over a local network. Reports about pairing authorization, signaling, data exposure, credential handling, or unsafe action execution are in scope. Do not test against networks or devices you do not own or have permission to assess.
